# Contributing

Brooklet is built primarily for its maintainer's own use. It is GPL-licensed
free software, so the expected route for materially different priorities is to
fork it and make it yours. Pull requests are welcome, but there is no promise
that they will be reviewed, merged, released, or supported.

## Before opening an issue or pull request

- Do not report security vulnerabilities in public; use [SECURITY.md](SECURITY.md).
- Keep changes focused and explain the user-visible or security reason.
- Do not add analytics, advertising, telemetry, remote configuration, or a
  Brooklet-operated backend.
- Preserve the offline-first model: Room is the UI source of truth and local
  actions must remain durable while offline.
- Run the checks in the README. Include test coverage for behavioural or
  security changes.
- Confirm you have the right to contribute any code, artwork, text, or assets.

## Support expectations

The maintainer cannot provide individual setup help, diagnose third-party
Miniflux/Karakeep installations, or guarantee device/version compatibility.
Forking is encouraged where that is a better fit.
